## 1. 系统概述

### 1.1 背景

当前爬虫程序 `get_1688_xindeyi.py` 需要在本地手动运行，无法实现远程控制和自动化调度。本系统旨在通过服务端-客户端架构，实现远程下发爬取指令、实时监控任务进度、自动上报执行结果。

### 1.2 目标

- 服务端可远程下发爬取任务
- 客户端自动接收指令并执行
- 实时上报任务进度和状态
- 支持多客户端并发管理

### 1.3 术语定义

| 术语 | 说明 |
|------|------|
| 服务端 | Flask Web服务，负责任务调度和状态管理 |
| 客户端 | 运行爬虫程序的本地机器 |
| 任务 | 一次完整的爬取会话 |
| 批次 | 单次爬取生成的数据批次 |
| 心跳 | 客户端定时向服务端发送的状态报告 |

```
│                     阿里云OSS存储                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 数据流

```
1. 管理后台创建任务 → 存入数据库
2. 客户端发送心跳 → 服务端返回待执行任务
3. 客户端执行爬取 → 实时上报进度
4. 爬取完成 → 上传OSS → 上报结果
5. 管理后台查看结果
```

## 4. 通信协议

### 4.1 数据格式

所有接口统一使用JSON格式，响应结构：

```json
{
    "code": 200,
    "message": "success",
    "data": {}
}
```

### 4.2 心跳机制

#### 请求

```http
POST /api/client/heartbeat
Content-Type: application/json

{
    "client_id": "client_001",
    "status": "idle",
    "current_task": null,
    "timestamp": "2026-04-23T15:30:00Z"
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| client_id | string | 是 | 客户端唯一标识 |
| status | string | 是 | 状态：idle/running/error |
| current_task | string | 否 | 当前执行的任务ID |
| timestamp | string | 是 | ISO8601格式时间 |

#### 响应

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "instruction": "start_crawl",
        "task_id": "task_20260423153000",
        "params": {
            "shop_url": "https://xindeyi.1688.com",
            "max_pages": 5,
            "upload_oss": true
        }
    }
}
```

**instruction字段说明：**

| 值 | 说明 |
|----|------|
| none | 无指令，继续等待 |
| start_crawl | 开始爬取 |
| stop_crawl | 停止当前任务 |
| restart | 重启客户端 |

### 4.3 任务进度上报

#### 请求

```http
POST /api/client/task_report
Content-Type: application/json

{
    "client_id": "client_001",
```

**status字段说明：**

| 值 | 说明 |

| pending | 等待执行 |
| running | 执行中 |

## 5. 数据库设计

### 5.1 实体关系图

```
┌─────────────┐       ┌─────────────┐       ┌─────────────┐
│   clients   │       │    tasks    │       │  task_logs  │
├─────────────┤       ├─────────────┤       ├─────────────┤
│ id          │       │ id          │       │ id          │
│ client_id   │◄──────│ client_id   │       │ task_id     │
│ name        │       │ task_id     │◄──────│ level       │
│ status      │       │ status      │       │ message     │
│ ...         │       │ params      │       │ created_at  │
└─────────────┘       │ result      │       └─────────────┘
                      │ ...         │
                      └─────────────┘
```

### 5.2 表结构

#### clients（客户端表）

```sql
CREATE TABLE clients (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    client_id       VARCHAR(50) UNIQUE NOT NULL COMMENT '客户端唯一标识',
    name            VARCHAR(100) COMMENT '客户端名称',
    ip_address      VARCHAR(50) COMMENT 'IP地址',
    status          VARCHAR(20) DEFAULT 'offline' COMMENT '状态：offline/online/busy',
    last_heartbeat  DATETIME COMMENT '最后心跳时间',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间'
);
```

#### tasks（任务表）

```sql
CREATE TABLE tasks (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id         VARCHAR(50) UNIQUE NOT NULL COMMENT '任务唯一标识',
    client_id       VARCHAR(50) COMMENT '分配的客户端',
    status          VARCHAR(20) DEFAULT 'pending' COMMENT '状态：pending/running/completed/failed/cancelled',
    instruction     VARCHAR(50) COMMENT '指令类型',
    params          TEXT COMMENT '任务参数（JSON格式）',
    result          TEXT COMMENT '执行结果（JSON格式）',
    progress        TEXT COMMENT '进度信息（JSON格式）',
    started_at      DATETIME COMMENT '开始时间',
    completed_at    DATETIME COMMENT '完成时间',
    created_at      DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间'
);
```

#### task_logs（任务日志表）

```sql
CREATE TABLE task_logs (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id     VARCHAR(50) COMMENT '关联任务ID',
    level       VARCHAR(20) COMMENT '日志级别：info/warning/error',
    message     TEXT COMMENT '日志内容',
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间'
);
```

### 5.3 索引设计

```sql
-- 客户端状态查询
CREATE INDEX idx_clients_status ON clients(status);

-- 任务状态查询
CREATE INDEX idx_tasks_status ON tasks(status);

-- 客户端任务查询
CREATE INDEX idx_tasks_client ON tasks(client_id);

-- 日志查询
CREATE INDEX idx_logs_task ON task_logs(task_id);
```

### 7.2 核心类设计

#### ClientAPI 类

```python
class ClientAPI:
    """服务端通信客户端"""
    
    def __init__(self, client_id: str, server_url: str):
        self.client_id = client_id
        self.server_url = server_url
        self.session = requests.Session()
    
    def heartbeat(self) -> dict:
        """发送心跳，获取指令"""
        pass
    
    def report_progress(self, task_id: str, progress: dict):
        """上报任务进度"""
        pass
    
    def report_result(self, task_id: str, result: dict):
        """上报任务结果"""
        pass
```

#### TaskManager 类

```python
class TaskManager:
    """任务管理器"""
    
    def __init__(self, api_client: ClientAPI):
        self.api = api_client
        self.current_task = None
        self.running = False
    
    def start_task(self, task_id: str, params: dict):
        """开始执行任务"""
        pass
    
    def stop_task(self):
        """停止当前任务"""
        pass
    
    def run(self):
        """主循环"""
        while True:
            # 发送心跳
            resp = self.api.heartbeat()
            
            # 解析指令
            instruction = resp.get('instruction')
            
            if instruction == 'start_crawl':
                self.start_task(resp['task_id'], resp['params'])
            elif instruction == 'stop_crawl':
                self.stop_task()
            
            time.sleep(5)
```

### 7.3 主程序流程

```python
def main():
    """程序入口"""
    # 初始化
    config = load_config()
    api = ClientAPI(config.client_id, config.server_url)
    manager = TaskManager(api)
    
    # 启动主循环
    try:
        manager.run()
    except KeyboardInterrupt:
        print("程序已停止")
    except Exception as e:
        logger.error(f"程序异常: {e}")

if __name__ == '__main__':
    main()
```

```bash

# 2. 创建虚拟环境

pip install -r requirements.txt

# 4. 初始化数据库
```

## 9. 安全设计

### 9.1 认证机制

- 客户端使用 `client_id` + `secret_key` 进行身份验证
- 每次请求携带 `Authorization` 头部

```http
Authorization: Bearer <token>
```

### 9.2 数据加密

- 敏感数据传输使用 HTTPS
- 数据库密码使用 bcrypt 加密存储

### 9.3 访问控制

- 管理后台需要登录认证
- API接口限流（每分钟100次）

### 9.4 日志审计

- 记录所有API请求日志
- 保留30天操作记录
