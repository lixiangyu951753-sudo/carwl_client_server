# 爬虫客户端-服务端项目优化建议

## 一、代码结构问题

### 1.1 函数过长，职责不单一

**文件**: `client/main.py`

**问题**: `shop_detail()` 函数长达 153 行，同时处理：
- 页面元素提取（图片、价格、供应商、描述）
- 文件下载（图片、视频）
- 文件系统操作（创建文件夹）
- 数据组装返回

**优化建议**: 拆分为多个小函数：
```python
def extract_images(tab) -> list:
    """提取商品图片"""
    ...

def extract_price(tab) -> tuple:
    """提取价格信息，返回 (min, max)"""
    ...

def extract_supplier(tab) -> dict:
    """提取供应商信息"""
    ...

def download_media(urls: list, folder: str):
    """下载媒体文件"""
    ...
```

### 1.2 嵌套层级过深

**文件**: `client/main.py` - `shop_list()` 函数

**问题**: 三重嵌套循环 + 异常处理，可读性差
```python
while retry_count < max_retry:          # 第1层
    try:
        while True:                      # 第2层
            for div in divs:             # 第3层
                ...
```

**优化建议**: 提取为独立函数，减少嵌套

## 二、错误处理问题

### 2.1 空异常捕获（最严重）

**文件**: `client/main.py`

**问题代码**:
```python
# 第 152-154 行
except:
    lib_video = None
    print('未找到视频')

# 第 184-185 行
except:
    pass

# 第 196-197 行
except:
    pass

# 第 204-205 行
except:
    pass
```

**风险**: 
- 隐藏真正的错误，难以调试
- 可能捕获 KeyboardInterrupt，导致无法 Ctrl+C 退出
- 不符合 PEP 8 规范

**优化建议**:
```python
except Exception as e:
    logger.warning(f"未找到视频元素: {e}")
    lib_video = None
```

### 2.2 服务端接口缺少异常处理

**文件**: `server/app/routes/client.py`

**问题**: `task_result()` 和 `task_report()` 没有处理 MongoDB 连接异常

**优化建议**:
```python
@bp.route('/task_result', methods=['POST'])
def task_result():
    try:
        # 原有逻辑
        ...
    except pymongo.errors.ConnectionFailure:
        return jsonify({"code": 500, "message": "数据库连接失败"}), 500
    except Exception as e:
        logger.error(f"处理任务结果时出错: {e}")
        return jsonify({"code": 500, "message": "内部服务器错误"}), 500
```

## 四、日志系统缺失

### 4.1 使用 print 代替日志

**文件**: `client/main.py`, `client/api_client.py`, `client/task_manager.py`

**问题**: 大量使用 `print()` 输出信息，无法：
- 按级别过滤（DEBUG/INFO/WARNING/ERROR）
- 输出到文件
- 按时间轮转
- 在生产环境关闭调试输出

**优化建议**:
```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('crawler.log'),
        logging.StreamHandler()
    ]
)
logger = logging.getLogger(__name__)

# 使用
logger.info(f"任务ID: {task_id}")
logger.warning("未找到视频")
logger.error(f"任务执行失败: {e}")
```

## 六、安全问题

### 6.1 没有输入验证

**文件**: `server/app/routes/client.py`

**问题**: `task_result()` 直接接收客户端数据并插入数据库，没有验证：
```python
data = request.get_json()
products = data.get('products', [])
# 直接遍历插入，没有验证数据结构
for product in products:
    db.collector_items.insert_one(item)
```

**风险**: 客户端可能发送恶意数据

**优化建议**:
```python
from marshmallow import Schema, fields, validate

class ProductSchema(Schema):
    title = fields.Str(required=True, validate=validate.Length(max=500))
    url = fields.Url(required=True)
    images = fields.List(fields.Url())
    priceMin = fields.Str()
    priceMax = fields.Str()

schema = ProductSchema(many=True)
products, errors = schema.load(data.get('products', []))
if errors:
    return jsonify({"code": 400, "message": "数据格式错误", "errors": errors}), 400
```

### 6.2 没有请求限流

**风险**: 客户端频繁请求可能导致服务端过载

**优化建议**: 使用 Flask-Limiter
```python
from flask_limiter import Limiter

limiter = Limiter(app, key_func=lambda: request.json.get('client_id'))

@bp.route('/heartbeat', methods=['POST'])
@limiter.limit("60 per minute")
def heartbeat():
    ...
```

## 七、性能问题

### 7.1 频繁文件读写

**文件**: `client/main.py`

**问题**: `save_task()` 每次都要读取整个文件、修改、再写入
```python
def save_task(task_id, status, ...):
    tasks = load_tasks()  # 读取整个文件
    tasks[task_id] = {...}
    with open(tasks_file, 'w') as f:
        json.dump(tasks, f)  # 写入整个文件
```

**优化建议**: 使用 SQLite 或批量保存
```python
# 批量保存，减少IO
def save_tasks_batch(tasks_data: list):
    tasks = load_tasks()
    tasks.update(tasks_data)
    with open(tasks_file, 'w') as f:
        json.dump(tasks, f)
```

### 7.2 数据库查询没有索引

**文件**: `server/app/__init__.py`

**问题**: MongoDB 没有创建索引，查询性能差

**优化建议**:
```python
def create_app():
    ...
    # 创建索引
    db.collector_tasks.create_index("taskId", unique=True)
    db.collector_tasks.create_index("status")
    db.collector_items.create_index("taskId")
    db.collector_items.create_index("dedupeKey", unique=True)
    ...
```

### 7.3 没有连接池

**文件**: `server/app/__init__.py`

```python
mongo_client = MongoClient(app.config['MONGO_URI'])  # 默认连接池
```

**优化建议**:
```python
mongo_client = MongoClient(
    app.config['MONGO_URI'],
    maxPoolSize=50,
    minPoolSize=10,
    maxIdleTimeMS=45000
)
```
