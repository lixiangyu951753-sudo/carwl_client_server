# 爬虫端对接运营工作台改造文档

## 一、运营工作台功能分析

根据运营工作台界面，包含以下核心模块：

| 模块 | 功能说明 | 与爬虫端的关系 |
|------|----------|----------------|
| **采集概览** | 展示采集中心运行状态总览 | 需要爬虫端上报实时状态数据 |
| **采集源管理** | 管理采集源（店铺/网站） | 爬虫端接收采集源URL执行爬取 |
| **采集任务** | 创建和管理采集任务 | 爬虫端接收任务并执行 |
| **解析结果** | 查看采集后的解析结果 | 爬虫端上报解析后的商品数据 |
| **待校正** | 需要人工校正的数据 | 爬虫端标记低置信度数据 |
| **媒体采集库** | 采集的图片/视频资源 | 爬虫端上报媒体文件信息 |
| **去重合并** | 商品去重和数据合并 | 爬虫端提供原始数据 |
| **采集质检** | 采集数据质量检查 | 爬虫端上报采集质量指标 |
| **采集日志** | 采集过程日志记录 | 爬虫端上报运行日志 |

---

## 二、爬虫端改造目标

### 2.1 核心改造点

1. **任务接收**：从运营工作台接收采集任务（采集源URL、采集规则）
2. **数据上报**：将采集结果按运营工作台要求的格式上报
3. **状态同步**：实时同步采集进度和状态
4. **日志记录**：记录采集过程日志供运营工作台查询

### 2.2 数据对接关系

```
运营工作台                    爬虫端
    |                           |
    |-- 创建采集任务 ----------->|
    |   (采集源URL、规则)        |
    |                           |
    |<-- 任务状态上报 -----------|
    |   (running/completed)      |
    |                           |
    |<-- 进度上报 ---------------|
    |   (当前页/当前商品)         |
    |                           |
    |<-- 解析结果上报 -----------|
    |   (商品数据JSON)           |
    |                           |
    |<-- 媒体信息上报 -----------|
    |   (图片/视频URL列表)        |
    |                           |
    |<-- 采集日志上报 -----------|
    |   (运行日志)               |
```

### 3.2 爬虫端 main.py 改造

#### 3.2.1 crawl_callback 函数改造

**当前：**
```python
def crawl_callback(task_id: str, params: dict):
    shop_url = params.get('shop_url')
    max_pages = params.get('max_pages')
```

**改造后：**
```python
def crawl_callback(task_id: str, params: dict):
    """任务管理器回调函数 - 适配运营工作台"""
    shop_url = params.get('source_url') or params.get('shop_url')
    crawl_config = params.get('crawl_config', {})
    parse_config = params.get('parse_config', {})
    
    max_pages = crawl_config.get('max_pages', 10)
    max_products = crawl_config.get('max_products', 500)
    crawl_images = crawl_config.get('crawl_images', True)
    crawl_videos = crawl_config.get('crawl_videos', True)
    crawl_factory_images = crawl_config.get('crawl_factory_images', True)
    save_html = crawl_config.get('save_html', True)
    
    extract_fields = parse_config.get('extract_fields', [])
    
    if shop_url:
        print(f"[爬虫] 打开店铺: {shop_url}")
        browser.get(shop_url)
        browser.latest_tab.wait(3)
    else:
        print(f"[爬虫] 未提供店铺URL，任务 {task_id} 使用浏览器默认打开的网页")
        browser.latest_tab.wait(1)

    result = shop_list(
        server_task_id=task_id, 
        shop_url=shop_url,
        max_pages=max_pages,
        max_products=max_products,
        crawl_images=crawl_images,
        crawl_videos=crawl_videos,
        crawl_factory_images=crawl_factory_images,
        save_html=save_html,
        extract_fields=extract_fields
    )
    return result
```

def shop_detail(batch_id: str, server_task_id: str = None, extract_fields: list = None):

### 3.3 api_client.py 改造

#### 3.3.1 新增日志上报接口

```python
def report_log(self, task_id: str, level: str, message: str):
    """上报采集日志"""
    data = {
        "client_id": self.client_id,
        "task_id": task_id,
        "level": level,
        "message": message,
        "timestamp": datetime.now().isoformat()
    }
    try:
        self.session.post(
            f"{self.server_url}/client/task_log",
            json=data, timeout=10
        )
    except Exception as e:
        print(f"[日志上报] 错误: {e}")
```

### 3.4 Server 端新增接口

#### 3.4.1 日志上报接口

```python
@bp.route('/task_log', methods=['POST'])
def task_log():
    """接收爬虫端日志"""
    from flask import request, jsonify
    from app.models import add_log
    
    data = request.get_json()
    task_id = data.get('task_id')
    level = data.get('level', 'info')
    message = data.get('message')
    
    if not task_id:
        return jsonify({"code": 400, "message": "task_id is required"}), 400
    
    add_log(task_id, level, message)
    
    return jsonify({"code": 200, "message": "success"})
```

#### 3.4.2 质检数据上报接口

```python
@bp.route('/task_quality', methods=['POST'])
def task_quality():
    """接收爬虫端质检数据"""
    from flask import request, jsonify
    from app import db
    
    data = request.get_json()
    task_id = data.get('task_id')
    quality = data.get('quality', {})
    
    if not task_id:
        return jsonify({"code": 400, "message": "task_id is required"}), 400
    
    db.tasks.update_one(
        {"task_id": task_id},
        {"$set": {"quality": quality, "updated_at": datetime.now()}}
    )
    
    return jsonify({"code": 200, "message": "success"})
```
